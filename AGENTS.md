# AGENTS.md

## Commands

- Type checking: `npx tsc --noEmit`
- Production build: `npx next build`
- Dev server: `npx next dev`
- Start production: `npx next start`

## Environment

This is a Next.js 16 (App Router) project using Turbopack for bundling.

## Env variables (.env.local)

- `NEXT_PUBLIC_GTM_ID` — Google Tag Manager container ID (e.g., `GTM-NXTPXRQK`)
